Encounter Editor MMVIII
===========================

Editor for CMN.NG2 and BTL files from Ninja Gaiden II, 
Xbox 360 game. GUI Application.
BTL files define enemy spawn types and other 
chapter-progression data.

There is no source code available. All information on how this tool examines game files can be found in following [documentation](https://github.com/ike9000e/dot-btl-editor-ng2/discussions/1).

[Preview](./im01.png)

[Preview Video, or Basic Tutorial](https://www.youtube.com/watch?v=J5PKTTShcdg)


Prerequisites
----------------

* Game as folder - the extracted ISO into directory. This is only to modify the "cmn.ng2" file. Only its small part is changed, no other game files will be altered.
*	Chapter-Completed game saves for every chapter of interest. This is to start every game-test session from the begin of the chapter. Since, in essence, mid-chapter saves won't be compatible with any modifications made.
* Running the game on Xenia emulator. 


File Details
-------------

"cmn.ng2" file is an archive that can be found on 
the Ninja Gaiden II game disc.
